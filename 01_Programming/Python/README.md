# Python for Placements

Python is the **primary language** for Data Science, ML, AI, and GenAI roles. It is also widely accepted in SDE coding rounds and is the standard for backend APIs (FastAPI, Flask) and MLOps tooling.

## Why Python Matters for Placements

| Role | How Python Is Used |
|---|---|
| SDE / Backend | Coding rounds, FastAPI/Flask, scripting |
| Data Scientist | pandas, NumPy, scikit-learn, stats |
| ML Engineer | PyTorch, TensorFlow, pipelines |
| GenAI Engineer | LLM APIs, LangChain, RAG |
| Data Engineer | Airflow, PySpark, ETL |
| MLOps | MLflow, Docker SDK, FastAPI |
| Cloud Engineer | Boto3, CDK, automation |

## What This Section Covers

1. **Core Concepts** — data types, control flow, functions, comprehensions, error handling
2. **OOP in Python** — classes, inheritance, dunder methods, decorators
3. **Advanced Python** — generators, iterators, closures, GIL, memory model, async
4. **Implementation** — executable code for key patterns
5. **Examples** — practical placement-relevant examples
6. **Common Mistakes** — traps that cost marks in interviews
7. **Interview Questions** — Level 1 to Level 5
8. **Problems** — coding problems with solutions
9. **Cheat Sheet** — one-page revision

## How to Use

- **First pass:** Read `concepts.md` + `oop_in_python.md` + `advanced_python.md`
- **Practice:** Run `implementation.py`, solve `problems.md`
- **Revise:** Use `cheatsheet.md` before interviews
- **Interview prep:** Study `interview_questions.md` + `common_mistakes.md`

## Prerequisites

- Basic programming awareness (any language)
- Python 3.10+ installed
- Comfort with running scripts and using `pip`
